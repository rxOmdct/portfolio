OTA — Hébergement web

Outil d'administration en Bash qui automatise la création et la gestion d'hébergements web sur un serveur Linux, façon mini panneau de contrôle.

Contexte

OTA est un outil en ligne de commande développé en Bash pour administrer un serveur d'hébergement web mutualisé. L'objectif est d'automatiser les tâches répétitives d'un hébergeur (création de comptes, sites, bases de données, accès FTP/SSH) à travers un menu interactif unique, plutôt que de taper manuellement chaque commande système.

Le projet est organisé en modules : un script principal (ota.sh) affiche le menu et appelle des scripts spécialisés selon le choix de l'administrateur.

Fonctionnalités

  • Créer un hébergement — compte utilisateur, mot de passe, quota disque, FTP, base de données et SSH en une seule procédure
  • Supprimer / modifier un hébergement — gestion du cycle de vie d'un compte
  • Lister les utilisateurs et consulter le détail de chacun
  • Gestion des bases de données (MariaDB)
  • Gestion des fichiers web — avec installation de WordPress en un clic
  • Gestion FTP (Pure-FTPd)
  • Informations serveur — espace disque, services actifs, sites hébergés, adresse IP
  • Installation des paquets requis (Apache, MariaDB, Pure-FTPd, quotas)

Création d'un hébergement, étape par étape

Le module de création enchaîne automatiquement les opérations système suivantes :

  • Création d'un utilisateur Linux dédié (useradd) et de son mot de passe
  • Mise en place d'un quota disque personnalisé (setquota)
  • Création d'un compte FTP pointant vers le dossier www (pure-pw)
  • Création optionnelle d'une base de données MariaDB
  • Activation optionnelle de l'accès SSH
  • Génération d'un VirtualHost Apache et activation du site (a2ensite)

Technologies utilisées

Bash Linux Apache2 MariaDB Pure-FTPd Quotas disque SSH WordPress

Compétences BTS SIO (SISR) mobilisées

  • Bloc 1 — Support et mise à disposition de services : installation et configuration de services (Apache, MariaDB, FTP), gestion des utilisateurs et des droits, supervision basique du serveur
  • Bloc 2 — Administration des systèmes et des réseaux : automatisation par scripts, gestion des quotas, déploiement reproductible d'un environnement d'hébergement

Bilan

Ce projet m'a permis de manipuler concrètement l'administration système Linux et de comprendre le fonctionnement interne d'un hébergeur web. La logique de scripting (menus, fonctions, conditions, gestion des erreurs) et l'enchaînement des services (Apache, base de données, FTP, quotas) rejoignent directement les compétences visées par mon orientation réseau / infrastructure.
